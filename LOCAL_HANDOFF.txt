v1.4 구현:
- 기본 전기 주행: 앞 1개·뒤 2개 모터 AWD 근사. 당시 발표 구성의 200 kWh, 초기 SOC 80%.
- W/가속 버튼: 선택한 D/R 방향 가속. S/Space/B: 마찰 브레이크. 브레이크가 가속보다 우선.
- 1/2 또는 D/R 버튼: 접지 및 수평 속력 0.5 m/s 미만에서 방향 선택.
- 가속 해제 시 회생제동·배터리 회수, 95–100% SOC에서 회수 제한. 저속 정지 유지.
- 수평 속도 km/h·m/s, 전진/후진 상태, 모터/회생 전력, 타이어 마찰 합력, 브레이크 요구력 표시.
- 건조/젖음/빙판 μ=1.15/0.65/0.15. 구동·제동·횡력·구름저항을 합쳐 μN 마찰 원 적용.
- μ=0에서 잔여 구름/차체 저항 제거. 공중에서는 접지력을 부여하지 않음.
- 전기 주행에서 가정 탱크 질량·추진기·팬·윙 제외. 별도 비행 실험으로 기존 도약/스테이지 보존.
- 캐시 버전 v=20261107-drive1; main의 physics/controls/scene/learning import도 갱신.

실제 데이터와 근사 구분:
- 2017 공식 공개 영상의 3모터 AWD/200 kWh는 당시 발표 구성. 2026 Rocket이나 1세대 부품 사양을 섞지 않음.
- 회생·제동·정지 유지 원리는 일반 Tesla EV 설명서 참고. 2020 제어 소프트웨어를 재현한 것은 아님.
- 1,900 kg, 650 kW, 900 N·m, 앞:뒤 토크 1:2, 회생 1.8 m/s²/80 kW/72% 및 노면 계수는 교육용 가정.
- 정밀 ABS/TCS/토크 벡터링·배터리 온도 제한·실측 타이어/공력 지도 생략. 계산 속도/정지거리/가속은 실차 성능 검증이 아님.

배포 방식:
- main의 .github/workflows/pages.yml이 dist/를 배포. Pages build_type=workflow 유지.
- dist/**, tests/**, package*.json, workflow 변경 push가 자동 배포. 문서만 변경하면 배포하지 않음.
- npm ci --ignore-scripts, npm run check, npm test 후 commit/push. 정상 Git 인증 사용, 인증값 출력/저장/커밋 금지.
- gh-pages는 과거 스냅샷. scripts/publish_pages.py 및 scripts/deploy_github.py는 이전 방식이므로 실행하지 않음.
- 모델(CC BY 4.0)/Three.js 라이선스·저작자 표시와 기존 이력을 보존하고 강제 push하지 않음.
