배포 방식:
- main의 .github/workflows/pages.yml이 dist/를 배포. Pages Source는 GitHub Actions (build_type: workflow).
- github-pages 환경은 main 배포를 허용. gh-pages는 과거 스냅샷이며 현재 배포 소스가 아님.
- dist/**, tests/**, package*.json, workflow 변경 push가 자동 배포를 시작함. 문서만 변경하면 배포하지 않음.
- npm ci --ignore-scripts, npm run check, npm test 실행 후 커밋하고 main에 push. 기존 이력 보존, 강제 push 금지.
- scripts/publish_pages.py 및 scripts/deploy_github.py는 이전 방식용이므로 실행하지 않음. 후자는 Pages 소스를 gh-pages로 되돌릴 수 있음.
- 인증은 PC의 정상 Git 인증 사용. 인증값을 출력·저장·커밋하지 않음. 모델/Three.js 라이선스와 저작자 표시 유지.
