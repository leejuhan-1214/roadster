Roadster PC 작업 인계

목표: 이 폴더의 시뮬레이터를 https://github.com/leejuhan-1214/roadster 에 업로드하고
https://leejuhan-1214.github.io/roadster/ 에 GitHub Pages로 배포한다.
사용자는 파일 업로드와 공개 배포를 이미 명시적으로 승인했다.

현재 상태:
- 시뮬레이터 구현 완료. 마지막 검증에서 테스트 47개 통과.
- dist/가 배포할 정적 파일 전체이며 Three.js와 Tesla Roadster 모델이 포함되어 있다.
- GitHub Pages /roadster/ 경로에 맞춰 상대경로 수정 및 dist/.nojekyll 준비 완료.
- scripts/deploy_github.py가 main 업로드, gh-pages 생성, Pages 설정을 자동화한다.
- 압축 파일에는 .git과 인증 정보가 없다. 기존 PC의 Git 인증을 정상적인 방법으로 사용한다.
- 클라우드 연결에서 업로드가 403으로 거부되어 로컬 PC에서 이어서 작업한다.
- 마지막 확인 당시 원격 저장소는 비어 있었고 Pages가 비활성 상태였다. 실행 전에 최신 상태를 확인한다.

이어 할 작업:
1. 현재 실행 환경이 Windows 로컬 PC인지 확인한다.
2. Git과 GitHub 인증 계정 및 대상 저장소 접근을 확인한다. 인증값은 출력하지 않는다.
3. 기존 원격 커밋이 있으면 보존하며 통합하고, 강제 push하지 않는다.
4. 가능하면 python scripts/deploy_github.py 실행. 필요한 도구가 없으면 설치 또는 동등한 배포 절차를 사용한다.
5. gh-pages 브랜치 루트에 dist 내용이 오도록 배포하고 Pages 빌드 성공을 확인한다.
6. 공개 URL의 HTML, JS, Tesla scene.gltf와 scene.bin 응답을 확인한다.
7. 실제 배포가 확인된 뒤 완료를 보고한다. 새 시뮬레이터를 다시 만들 필요는 없다.

조작: 마우스 회전, WASD 이동/공중 제어, Space 분사, R 리셋.
스테이지 시작 버튼과 구조 탐색 모드의 스크롤 분해 기능이 구현돼 있다.
실제 차량의 비공개 사양은 가정값이며 정밀 실차 재현을 주장하지 않는다.
