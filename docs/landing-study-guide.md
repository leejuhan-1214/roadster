# 부양 차량의 착지 충격과 연료 소비 탐구 · v1.44

## 탐구 질문과 가설

같은 차체가 같은 높이에서 부양하다 착지할 때, 추력 제어 방식에 따라 지면 반력과 연료 소비가 어떻게 달라지는가? 하강 속도를 줄이고 감속 시간을 늘리면 충격은 줄어들지만 지속 분사에는 연료가 필요하다. 연료를 최소화하는 조건과 반력을 최소화하는 조건이 같지 않을 것으로 예상한다.

## 현재 장치와 실험 절차

주변 공기를 흡입해 연료와 연소하는 제트엔진을 사용한다. 상승 64기와 보조 6기의 외부 실험 장치이며 실차 순정 부품은 아니다. 엔진 최대 추력·무게·연료 유량은 JetCat P1000-PRO 공개 제원, 설치 효율 0.85와 프레임·부분 출력 특성은 가정이다. [출처와 한계](v144-jet-sources.md)를 보고서에 함께 적는다.

1. 차체를 선택하고 부양 높이 2 m, 지정 제동 높이 1 m, 목표 접촉 속도 0.5 m/s를 설정한다.
2. 상승 엔진 시동 완료 조건에서 지상 → 실제 추력 상승 → 안정 부양을 거친다. 높이 오차 5 mm 이내, 수직 속도 0.005 m/s 미만을 0.4 s 유지한 뒤 착지 단계를 시작한다.
3. 추력 차단, 지정 높이 재가속, 완만한 하강, 절약 착지를 비교한다. 절약은 점화를 유지하면서 제한된 하강 속도 후보 중 연료 소비가 적은 조건을 고른다.
4. 준비 연료와 착지 연료를 분리하고 전체 합계도 적는다. 동일 차체의 네 방식은 동일한 준비 제어와 착지 시작 상태를 사용한다. 각 방식은 원점에서 새 초기조건으로 시작한다.
5. 500 Hz로 적분하고 최대 20 ms 평균 등가반력, 접촉 속도, 연료, 압축량, 차체 접촉과 정착 여부를 기록한다. 냉간 시동의 시간·연료는 제외한 조건임을 명시한다.

독립변인: 착지 제어 방식. 종속변인: 최대 평균 반력·접촉 속도·소비 연료. 통제변인: 같은 차체, 부양 높이, 시작 연료, 준비 제어, 중력, 지면, 스프링 70 kN/m와 감쇠 4 kN·s/m. 차종을 바꾸면 질량뿐 아니라 형상·관성도 달라지므로 순수한 질량 효과라고 단정하지 않는다.

## 핵심 물리

- 수직 방향 운동: N + T_y − mg = ma_y. 접촉 전에는 N=0, 부양에서는 T_y≈mg이다. 연료 사용으로 m은 감소한다.
- 제트 추력: F = ṁ_out v_out − ṁ_in v_in + (p_out−p_ambient)A. 외부 공기가 계속 들어오는 열린 계이다. 저장 연료만 차체에서 줄고 흡입 공기는 탱크에 쌓이지 않는다.
- 로켓방정식: 외력이 없고 일정한 상대 배기속도로 자체 추진제를 방출하는 이상 로켓에서 Δv = v_e ln(m_0/m_f). 여기서는 공기 흡입과 중력이 있으므로 이 식에 저장 연료만 대입해 속도를 계산하면 안 된다. 일반 운동량 유량식을 사용한다.
- 충격량: J=∫Fdt. 같은 운동량 변화라면 힘을 가하는 시간을 늘려 평균 힘을 줄일 수 있다. 단, 지면 반력의 충격량과 알짜힘의 충격량을 구분하고 중력·추력도 함께 고려한다.
- 에너지: 하강 중 위치에너지가 운동에너지로 바뀌고, 스프링은 ½kx²를 저장하며 감쇠는 에너지를 소산한다. 제트에는 연료의 화학에너지와 흡기·배기 에너지 흐름이 있으므로 차체의 mgh+½mv²만으로 전체 에너지 보존을 검증하지 않는다.
- 엔진 응답: 공회전↔최대 출력 약 5초를 모델에 반영했다. 따라서 낮은 높이에서 뒤늦게 추력을 높이면 접촉 전 감속 시간이 부족하다. 연료 차단 후 순간 재점화도 가정하지 않는다.

## 보고서에 넣을 결론과 오차

같은 부양 상태에서도 추력의 시점과 크기를 조절하면 접촉 전 운동량을 줄일 수 있다. 이번 조건에서는 완만한 하강이 가장 낮은 반력을, 절약 착지가 적은 추가 연료로 비슷한 수준의 반력을 보였다. 이는 측정한 후보와 가정 안의 결과이며 전역 최적해는 아니다. 결정론적 시뮬레이션을 같은 조건으로 반복한 값은 독립적인 실제 측정 반복과 다르다.

오차·한계: 설치 손실, 부분 출력 보간, 고정 관성, 단순 접촉·서스펜션, 실제 배기 재흡입과 열 영향 생략, 실물 프레임 검증 부재. 후속 탐구에서는 부양 높이·목표 속도·설치 효율을 하나씩 바꿔 민감도를 확인하고, 가능한 실제 측정과 비교한다. 실험 데이터와 출처 제원, 설계 가정은 구분하여 제시한다.

이 조건에서는 절약 착지가 완만한 하강보다 총 소비량을 약 **12.0%** 줄이면서 등가반력은 41.02→41.94 kN으로 조금 높아졌다. 자유낙하 대비 등가반력 감소율은 약 **45.6%**다. 이는 충격과 기체 소비의 절충 사례다. 절약 착지는 제한된 후보 시점을 예측하여 선택하는 제어이며, 모든 높이·차체에서 연료의 전역 최솟값이나 목표 접촉 속도를 보장하지 않는다. 이번 결과의 계획 가능 여부도 **불가능(false)**로 기록되며, 가능한 만큼 제동한 결과를 그대로 표시한다.

### 3 m는 정상 착지 비교 범위를 벗어남

같은 소스로 검사한 3 m의 20개 조합은 모두 차체 바닥 접촉 또는 압축 한계 초과가 발생했다. Roadster의 첫 접촉 속도는 자유낙하 7.669, 지정 분사 7.246, 완만한 하강 6.956, 절약 착지 6.936 m/s였다. 추력의 일부 제동 효과는 있지만 정상 착지를 달성한 결과가 아니다. 해당 조건의 반력 최고값은 단순화된 접촉·위치 보정의 영향이 크므로 **실제 차량 추락 충격력, 차체 손상 또는 탑승자 부상 예측으로 사용하지 않는다.** 보고서의 정상 착지 방식 비교에는 위 0.20 m 표를 쓰고, 3 m는 장치와 모형의 한계를 보여 주는 실패 사례로 분리한다.

### 결과와 연결할 물리 개념

1. **중력 위치에너지와 운동에너지:** 무추력 검산은 v=√(2gh)이다. h=0.20 m에서 약 1.981 m/s로 자유낙하 결과와 일치한다. 처음 위치에너지 약 3.65 kJ는 접촉 직전 운동에너지의 규모를 설명한다. 분사는 하강 중 위쪽 힘으로 음의 일을 하므로 접촉 에너지를 줄인다.
2. **운동량과 충격량:** 위쪽을 양으로 두고 상대 배출 속도로 추력 T를 정의하면 m·dv/dt=N+T−mg이다. 공기저항이 유효하면 해당 힘도 더한다. 질량이 일정한 구간에서는 Δp=∫(N+T−mg)dt이고, 분사로 질량이 바뀌는 차량 자체의 운동량에는 d(mv)/dt=m·dv/dt+v·dm/dt를 적용한다. 분사 중에도 질량을 고정한 충격량 식을 그대로 쓰지 않는다. 지면 반력 N만을 순힘 또는 차체 가속도와 혼동하지 않는다.
3. **힘의 측정 기준:** 표의 값은 고정 20 ms 동안 반력을 적분하고 접촉 보정 충격량을 더한 뒤 0.020 s로 나눈 값의 최대값이다. 순간 최고 힘도, 전체 접촉 시간 평균도 아니다. 20 ms는 동일한 비교를 위한 보고 기준이며 안전 인증 기준이 아니다.
4. **로켓 방정식과 추력:** 이상적인 외력 없는 가변 질량계에서는 Δv=vₑ ln(m₀/mf)이다. 실제 착지 계산은 중력·접촉력·온도·압력·유량 변화를 포함하여 m·dv/dt=T+N−mg 등을 적분한다. 추력은 T=ṁvₑ+(pₑ−pₐ)Aₑ이며 로켓 방정식만으로 지면 접촉 속도를 확정하지 않는다. 밸브와 노즐을 직렬로 연결한 유량 제한을 반영하므로 탱크 압력이 노즐에 손실 없이 모두 전달된다고 가정하지 않는다.
5. **탄성력과 감쇠:** 바퀴의 압축에 따라 탄성 반력과 감쇠력이 생기며, 범프 스톱 구간에서는 추가 비선형 힘이 작용한다. 감쇠로 운동에너지가 소산되고 접촉 시간이 달라진다. k·c·유효 압축 한계는 공통 비교 장치의 값이며 각 실차의 실측 서스펜션 값이 아니다.
6. **열역학과 에너지 보존:** 분사 때 저장 기체의 질량·내부에너지가 줄고 온도·압력이 변한다. 차가워진 기체는 운용 온도 하한에서 유량이 제한된다. 충전은 주변 공기를 외부 전기에너지로 압축하는 과정이다. 주변 공기를 쓴다는 이유로 기체 재생에 에너지가 들지 않는 것은 아니다.

## 1. 연구 문제와 평가 기준

> 같은 높이에서 내려오는 가상 Roadster에서, 작은 접촉 속도와 정착을 유지하면서 기체 소비량과 최대 등가반력을 함께 줄일 수 있는 제동 시점과 방식은 무엇인가?

“충격을 줄였다”에서 끝내지 않고, 어느 조건에서 감소했는지와 그 대가로 필요한 기체량을 함께 설명한다. 너무 늦은 제동은 충분한 감속을 하지 못하고, 일찍 시작한 제동은 분사 시간이 길어질 수 있다는 가설을 세운다. 어느 조건이 실제로 우세한지는 측정값으로 판단한다.

제공된 2026학년도 고급물리학A 안내문의 평가는 총 20점이며 아래 네 항목이 각각 최대 5점이다. 실제 실험을 반드시 수행했다는 주장이 아니라, **실현 가능한 실험 설계와 시뮬레이션 예측의 근거**를 제시해야 한다.

## 2. 먼저 한 차체로 통제 실험하기

Roadster를 선택한 다음 제동·서스펜션을 펼쳐 **기본 3m 조건으로**를 누른다. 이 버튼은 현재 차체를 유지하고 아래 설정과 절약 착지 방식을 채우며 실험 자체는 시작하지 않는다.

| 항목 | 기본 연구 조건 |
| --- | --- |
| 차체·출발 높이 | Roadster, 바퀴 아래 3m |
| 초기 운동 | 속도·각속도 0, 수평 자세, 실험장 중심 |
| 비교 중 고정할 설정 | 목표 하강속도 0.5m/s, 고정 높이 제동 1.5m, 바퀴별 k=75kN/m, c=6kN·s/m |
| 초기 탱크 | 600L, 절대압력 35.875MPa, 300K, 기체 250kg |
| 공통 공급 조건 | 각 하부 노즐 단면적 0.0005m²로 동일; 공급 손실 계수 120; 자동 비교에서는 팬·공기 재충전·전기 구동·수동 조작 OFF |
| 환경 | g=9.80665m/s², 평탄면, 무풍, 공기저항 OFF, 장애물 없음 |
| 지면 | 접촉 마찰계수 1.15, 구름저항계수 0.015 |
| 계산 간격 | 0.002s, 즉 500Hz |

초기 총질량은 Roadster 기본 가정에서 2,150kg(기체 제외 1,900kg+공기 250kg)이다. 비교 차체의 초기 총질량은 MX-5 NA 1,340kg, M3 E30 1,600kg, Supra Mk IV 1,890kg, Roadster 2,150kg, Cybertruck 3,400kg이다. 분사 중에는 배출된 기체만큼 질량이 줄고 압력·온도도 변한다. 따라서 초기 조건이 같아도 접촉 때 질량이 다를 수 있다. 결과의 **접촉 직전 질량**을 함께 보존한다. 이 질량과 가상 추진 장치는 실차의 공인 제원이 아니다.

1. **4방식 비교**로 같은 Roadster의 자유낙하, 지정 높이부터 추력 제동, 완만한 하강 제어, 절약 착지를 같은 초기 조건에서 각각 한 번 실행한다. 총 4회이며 독립변인은 제어 방식이다.
2. **제동 높이 비교**로 자유낙하 기준 1회와 출발 높이의 10/25/50/75/100%에서 분사를 시작하는 5회를 실행한다. 3m에서는 0.3/0.75/1.5/2.25/3m이다. 이 묶음에서는 분사 시작 높이만 바뀐다.
3. 비교 결과를 저장한 뒤, 더 좁은 범위를 탐구하려면 같은 조건에서 제동 시작 높이를 세밀하게 바꿔 별도 기록한다. 서로 다른 묶음은 조건을 직접 확인해야 하며 사이트가 전체 기록을 한 순위로 합치지는 않는다.
4. 서스펜션은 후속 탐구로 진행한다. 제동 높이 등을 고정하고 k 또는 c 중 **하나만** 바꾼다. 동시에 높이·질량·스프링·감쇠를 모두 바꾸면 원인을 분리할 수 없다.

실험 전 자유 조종으로 이동하거나 기체를 써도, 실험 버튼을 누르면 출발 위치·속도·자세·탱크가 다시 초기화된다. 첫 접촉 전 Space로 수동 개입한 기록은 표시되며 자동 기준 비교와 절충 후보에서는 제외된다. 자동 실험의 주 연구 데이터에는 수동 개입을 하지 않는다.

**5차종 비교는 확장 탐구로 사용한다.** MX-5 NA, M3 E30, Supra Mk IV, Roadster, Cybertruck은 초기 질량뿐 아니라 치수·바퀴 위치·관성·충돌 외피도 다르다. 결과를 “질량만의 효과”나 실차 안전성 순위로 해석할 수 없다. 순수 질량 효과를 분리하려면 같은 형상과 관성 가정 등 다른 조건을 어떻게 유지할지 별도 모델 실험을 설계해야 한다. 도시·구조 탐색은 77종이지만 자동 착지 실험은 이 5종이다. **전체 5종 × 4방식**은 같은 높이에서 20회를 실행하고, **4방식 비교**는 현재 차체 하나의 4회다.

### 절약 착지를 연구 데이터로 사용하는 방법

여기서 '연료 절약'은 압축 공기의 배출 질량을 줄인다는 뜻이다. 절약 착지는 초기 상태로 무분사 낙하 후 제동하는 후보를 한 번 예측한다. 실행 후보에 완만한 하강 곡선을 넣거나 그 방식으로 자동 대체하지 않는다. 완만한 하강은 기체 사용량을 비교하는 참조 예측으로만 사용한다. 후보 중 목표 속도 허용 오차 안의 적격 조건을 찾고 예측 기체 사용량을 비교한다. 너무 늦은 제동은 밸브가 반응하고 속도를 줄일 거리를 잃게 하므로, 실제 유리한 정도는 접촉·기체 계측으로 확인한다.

최소 무분사 시간은 min(0.12초, 자유낙하 예상 시간의 15%)를 2ms 단계로 올림한다. 이는 분사 없는 낙하 단계를 구분하기 위한 제어 정책이며 자연 법칙이나 최적성 증명이 아니다. 제동 높이 조건과 시간 하한을 모두 만족해야 자동 분사를 시작한다. 0m/무추력으로 목표를 만족하는 낮은 출발점에서는 분사 없이 끝날 수 있다. Space 수동 개입은 이 자동 정책의 예외다.

계획기의 목적은 제한된 제어 후보에서 목표 접촉 속도를 제약으로 둔 기체 절약이다. 지면 최대 반력을 직접 최솟값으로 만드는 최적화나 가능한 모든 제어의 전역 해를 구한 것은 아니다. 반력은 접촉 속도뿐 아니라 접촉 때 질량·스프링·감쇠·압축 한계에도 영향을 받는다. 목표를 충족하는 예측 후보가 없으면 지연 제동 후보 중 대안을 실행할 수 있으며, 이때도 예측 실패 표시를 성공으로 바꾸지 않는다.

실제 진행은 500Hz 강체 계산이 담당한다. 목표 속도를 실제 속도에 대입하지 않고 유한 추력과 기체를 사용한다. 먼저 다음을 분리해 기록한다.

| 확인할 질문 | 기록할 값 |
| --- | --- |
| 예측에서 목표를 만족한 후보를 찾았는가? | `ecoPlanFeasible`, `ecoPredictedTouchdownSpeed` |
| 어떤 지연 제동 높이와 최소 무분사 시간을 계획했는가? | `ecoProfile`(brake/무분사 null), `ecoPlannedBrakeHeight`, `ecoMinimumCoastTime` |
| 제어는 실제 몇 m에서, 얼마나 기다린 뒤 시작했는가? | `autoBrakeHeight`, `ecoCoastTime` |
| 실제로 목표 접촉 속도에 도달했는가? | `targetSpeed`와 `touchdownSpeed`를 직접 비교 |
| 정착했고 차체·서스펜션 한계를 넘지 않았는가? | `status`, `settled`, `bodyStrike`, `bottomedOut`, 수동 개입 여부 |
| 기체와 반력은 실제 얼마나 줄었는가? | `gasUsed`, `peakEquivalentGroundForceN`와 같은 조건의 기준 결과 |

`autoBrakeHeight`와 `ecoCoastTime`은 **자동 제동 제어가 시작된 높이와 그 전 대기시간**이다. 밸브 지연 후 실제 유량이 처음 생긴 시점과 같다고 쓰면 안 된다. 최소 시간은 `ecoMinimumCoastTime`이고 실제 자동 명령 시각은 `ecoCoastTime`이다. 최초 양의 유량 표본의 끝 시각은 그 단계 시작보다 2ms 늦다. 화면의 무분사 낙하/착지 제동은 제어 플래그가 아니라 실제 추력으로 구분한다. `ecoPredictedTouchdownGas`는 접촉 전 사용량의 예측, `ecoPredictedGas`는 접촉 후 밸브가 닫히며 남기는 사용량까지 포함한 총예측이다. 각각 실제 `touchdownGasUsed`, `gasUsed`와 구별해 보존한다. 계산 단계 상한 안에 예측 접촉을 찾지 못한 높은 출발 조건에서는 예측 접촉 속도·기체가 빈칸이고 `ecoPlanFeasible=false`일 수 있다. 이 빈칸을 실제 접촉 속도 0 또는 기체 사용 0으로 바꾸지 않는다.

화면의 두 절감률은 다음처럼 **서로 다른 기준**을 쓴다.

- 기체 절감률: `100 × (1 − 절약 착지의 실제 총기체 / 완만한 하강의 실제 총기체)`.
- 반력 절감률: `100 × (1 − 절약 착지의 실제 최대 등가반력 / 지정 높이 제동의 실제 최대 등가반력)`.

같은 실험 묶음·차체·높이·목표 속도·스프링·감쇠·초기 질량·기체·탱크 용적·압력·온도일 때만 연결한다. 절약 착지와 완만한 하강은 정착하고 차체 접촉·서스펜션 한계·수동 개입이 없어야 한다. 고정 높이 제동은 실제 접촉을 측정했다면 큰 충격이나 진동도 반력 기준으로 사용할 수 있지만, 실패 상태를 숨기지 않는다. 증가한 값은 증가/음수로 남기며 기준이 부적격이면 절감률은 비운다. CSV의 `eco_gas_baseline_id`, `eco_force_baseline_id`로 각각 어떤 행과 비교했는지 재현할 수 있다.

보고서에는 '어느 비교에서 기체가 몇 % 바뀌고, 어느 비교에서 반력이 몇 % 바뀌었다'고 쓰고 같은 기준에 대한 결과처럼 합치지 않는다. **정착했더라도 목표 속도를 놓칠 수 있고, 예측에서 가능했어도 실제 측정은 다를 수 있다.** 낮은 기체 사용량 하나만 보고 차체 접촉·한계 초과를 좋은 착지로 분류하지 않는다. 높은 높이·무거운 차체·낮은 압력은 목표 미달을 드러내는 후속 탐구 조건이며, 전역 최소 연료나 모든 조건의 안전 착지를 입증하는 자료가 아니다.

후속 탐구에서는 높이 또는 초기 압력 등 하나만 바꾸어 같은 4회 비교를 수행한다. 사이트의 절감률은 각 묶음 안에서 계산하므로 서로 다른 높이의 행을 하나의 기준과 섞지 않는다. 보고서용 결과는 사용한 배포 버전과 직접 내보낸 CSV로 채우며, 아직 실행하지 않은 조건의 성능 수치를 예측값으로 대신 쓰지 않는다.

## 3. 물리량을 화면과 연결하기

`V`로 표시하는 중력·추력·지면 반력 화살표는 같은 힘 축척을 사용한다. 화살표를 실제 작용점으로 오해하지 않도록 차체 옆에 옮긴 도식임을 밝힌다. 추력은 개별 노즐의 힘을 벡터로 합한 값이며, 지면 반력 화살표는 연속 접촉력이다. 공중에서 지면과 접촉하지 않을 때 이 반력은 0이다. Three.js는 [ArrowHelper](https://threejs.org/docs/pages/ArrowHelper.html), 높이 눈금, 접촉 표식, 압축에 따라 바뀌는 스프링 도식을 렌더링한다. 이 표시는 물리 상태를 읽기만 한다.

실험 재생 속도 **1× / 0.25× / 0.1×**는 관찰용이다. `P`로 멈춘 뒤 **+2ms**를 누르면 한 물리 단계씩 진행한다. 모두 같은 2ms 계산을 사용하므로 재생 배속 비교를 계산 간격 수렴 검사라고 부르면 안 된다. 표시되는 수직 가속도에는 수치적 접촉 보정의 효과도 포함되며, 연속 힘 화살표만으로 이 순간값을 모두 설명할 수는 없다.

### 자유낙하 검산

추력·공기저항이 없고 초기 속도가 0이면 다음 식을 사용한다.

\[
v=\sqrt{2gh},\qquad t=\sqrt{\frac{2h}{g}}
\]

3m, g=9.80665m/s²에서 예상 속도는 약 7.670717m/s이다. 사이트는 이를 측정한 첫 접촉 직전 속도와 비교한다. 측정 속도를 이론값으로 덮어쓰지 않으므로 계산·접촉 판정에 따른 작은 차이가 남는다. 높이가 0이면 상대 오차의 분모가 0이므로 절대 차이만 제시한다. 기체를 배출한 실험에는 이 검산을 적용하지 않는다. [OpenStax: Free Fall](https://openstax.org/books/university-physics-volume-1/pages/3-5-free-fall).

### 로켓 방정식과 가변 질량

공기 분사는 연소 여부와 관계없이 질량 유출에 따른 운동량 변화로 추력을 만든다. 외력을 무시하고 압력 추력까지 포함한 유효 배기속도 `u_eq`가 일정하면 치올콥스키 로켓 방정식은 다음과 같다.

\[
\Delta v=u_{\mathrm{eq}}\ln\!\left(\frac{m_i}{m_f}\right)
\]

`m_i`와 `m_f`는 분사 전후의 차량 총질량이며, 여기의 Δv는 이상 조건에서 분사로 얻는 속도 변화다. 실제 착지에서는 중력과 지면반력, 변화하는 압력·온도를 함께 계산해야 한다. 위쪽을 양수로 잡고 공기저항을 생략하면 다음과 같다.

\[
m(t)\frac{dv_y}{dt}=N+T_y-m(t)g,
\qquad T=-u_{\mathrm{eq}}(t)\frac{dm}{dt}
\]

두 번째 식은 재충전 없이 기체를 방출하는 동안의 유효 추력 관계이며, 분사 시 `dm/dt<0`이다. 추력 방향이 기울어지면 수직식에는 `T_y`만 넣는다. 탱크 압력이 떨어지므로 일정 배기속도의 로그식에 수치만 넣어 실제 착지 속도를 대신할 수 없다. 자동 착지 비교에서는 질량·압력·유량·밸브 지연과 실제 힘을 2ms마다 계산한다. [NASA: Ideal Rocket Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/), [NASA: Rocket Thrust Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/rocket-thrust-equation/).

도시 주행의 X 롤 기동은 각 노즐의 위치에서 생기는 `τ=Σ(r×F)`와 관성으로 회전하지만, **보고서용 네 가지 자동 착지 실험에서는 이 기동을 사용하지 않는다.**

### 충격량과 운동량

위쪽을 양수로 잡으면 고정 질량에서 알짜 충격량이 운동량 변화와 같다.

\[
\Delta p_y=\int F_{\mathrm{net},y}\,dt
\]

이 프로그램의 무추력 기준 실험은 **출발부터 최종 측정 상태까지** 다음 항을 같은 구간에서 계산한다.

\[
\Delta p_y=\int N_{\mathrm{continuous}}dt+\sum J_{\mathrm{correction}}-\int mg\,dt
\]

최종 상태가 거의 정지이면 양의 지면 충격량과 음의 중력 충격량이 대부분 상쇄되어 알짜 충격량도 작아진다. **지면 충격량 자체가 작아야 한다는 뜻은 아니다.** 표의 “첫 감속 지면 충격량”은 더 짧은 구간이므로 이 전체 구간 검산에 섞지 않는다. 기체 배출은 차량 질량과 유출 기체의 운동량을 바꾸므로 고정 질량식으로 단순 검산하지 않는다. [OpenStax: Impulse and Collisions](https://openstax.org/books/university-physics-volume-1/pages/9-2-impulse-and-collisions).

### 스프링·감쇠와 에너지

이 화면의 x는 양의 압축량이고 ẋ는 압축 속도이다. 바퀴별 선형 구간의 근사는 다음과 같다.

\[
N_{\mathrm{wheel}}\approx\max(0,kx+c\dot{x}),\qquad E_s=\sum\tfrac12kx^2
\]

실제 코드에는 22cm 초과 압축의 비선형 범프 스톱과 차체 접촉도 있다. 선형 식만으로 모든 큰 충격을 설명하지 않는다. 감쇠가 작으면 반발이 오래 남을 수 있고, 감쇠가 지나치게 크면 빠른 압축 순간의 반력이 커질 수 있다. 압축 여유가 부족한 부드러운 스프링도 차체 접촉을 일으킬 수 있다. [OpenStax: Damped Oscillations](https://openstax.org/books/university-physics-volume-1/pages/15-5-damped-oscillations).

접촉 직전 에너지는 그 순간의 질량을 사용한 **수직 운동에너지** `½mᶜvᵧ²`다. 시간기록의 `kineticEnergyJ`는 병진 운동에너지, `potentialEnergyJ`는 수평·무압축 타이어 접촉 때의 무게중심 높이를 0으로 둔 중력 위치에너지, `springEnergyJ`는 선형 스프링 에너지다. 압축하면 이 기준의 위치에너지는 음수가 될 수 있다. 회전, 비선형 범프 스톱, 댐퍼 소산, 배출 기체의 에너지는 이 세 항의 합에 모두 포함되지 않는다. 이를 분사·충돌 중의 전체 에너지 보존량이라고 해석하지 않는다.

먼저 차체 접촉·서스펜션 한계 초과·진동 지속·미착지·수동 개입 결과를 구분한다. 안정 착지 후보 중에서 **다른 결과가 충격과 기체 사용량을 동시에 줄일 수 없는 조건**을 절충 후보(파레토 후보)로 표시한다. 한 지표가 같고 다른 지표가 더 나은 결과가 있어도 열등한 후보는 제외한다. 이는 측정한 조건들 사이의 비교이며 하나의 보편적인 최적값이나 실차 안전 인증이 아니다.

큰 충격 때문에 안정 착지끼리 차이가 잘 보이지 않으면 **안정 착지만 확대**를 사용할 수 있다. 전체 결과를 삭제하거나 숨긴 사실을 생략하지 말고, 보고서에는 전체 그래프와 확대 범위를 함께 제시한다. 그래프 SVG로 저장하면 발표 자료에 삽입해도 글자와 선이 선명하다.

요약 최댓값과 충격량은 2ms마다 계산한다. 시간 CSV의 힘·하중은 대체로 **10ms 구간의 최댓값**이므로 같은 행의 위치·속도와 정확히 같은 시각의 값이 아닐 수 있다. 이 점들을 다시 적분해 충격량을 만들지 말고 제공된 2ms 적분 요약값을 사용한다.

**이 표의 큰 힘은 연속 반력에 수치적 접촉 보정 충격량/2ms를 더한 값이다.** 재료의 실제 순간 응력·승객 하중·부상을 측정한 값이 아니다. 차체 접촉 결과는 감소율의 기준으로 남길 수 있지만 안정 착지 최적화 후보에는 포함하지 않는다.

자유낙하의 이론 속도 7.670717m/s와 측정 7.668800m/s의 상대 차이는 약 **0.02499%**다. 전체 2.284s에서 지면 충격량은 50,957.4244N·s, 중력 충격량은 −50,956.3341N·s, 알짜 충격량과 운동량 변화는 모두 약 1.090344N·s였다. 계산 잔차는 약 6.30×10⁻¹⁰N·s다. 이 작은 잔차는 수치 적분의 내부 일관성을 보여 주며, 실제 차량의 물리적 타당성을 실물로 검증했다는 뜻은 아니다.

## 6. 실현 가능한 축소 실험 설계

다음은 **제안하는 실험 설계**이며 이 프로젝트에서 실제로 측정한 실험은 아니다. 자동차를 떨어뜨리거나 실제 냉가스 장치를 제작할 필요 없이, 낙하·완충이라는 수동 부분을 분리해 검증할 수 있다.

```text
       높이 눈금 + 해제 장치
                 │
          [작은 추/모형]
          수직 가이드 레일   ← 옆에서 슬로모션 촬영
                 ↓
          [스프링·완충재]
             [힘센서]
             고정 받침
```

- **준비물:** 작은 추 또는 모형, 수직 가이드, 높이 눈금, 스프링·완충재, 힘센서와 데이터 수집 장치, 고정한 카메라. 추와 높이는 센서·가이드의 측정 범위에 맞춰 정한다.
- **독립변인:** 첫 실험은 낙하 높이 하나만 바꾼다. 다음 실험은 높이·질량을 고정하고 스프링 또는 완충재 하나만 바꾼다.
- **통제변인:** 동일 질량, 해제 방법, 초기 속도, 가이드, 센서 위치, 촬영 배율과 방향, 스프링 초기 상태.
- **정적 확인:** 힘센서를 영점 조정하고 알려진 질량의 하중으로 확인한다. 여러 정적 하중의 힘–압축량 기울기로 선형 구간의 k를 추정한다.
- **동적 측정:** 센서로 힘–시간을, 영상으로 접촉 속도·압축량·반발 높이를 구한다. 가이드 마찰, 카메라 원근, 눈금 해상도, 센서 샘플링 간격과 대역폭을 기록한다. 슬로모션 영상만으로 매우 짧은 최대 힘을 직접 측정했다고 쓰지 않는다.
- **반복과 해석:** 실제 실험은 같은 조건을 여러 번 반복해 평균·분산을 구할 수 있다. 완전히 같은 입력의 결정론적 시뮬레이션을 반복한 결과는 독립 실측 반복이나 오차 막대의 근거가 아니다.

실물로 확인할 수 있는 것은 자유낙하와 스프링·완충의 경향이다. 추진기의 압력·유량·밸브 제어와 Tesla 실제 구조까지 검증한 것으로 확대하지 않는다. 추력 제동의 축소 모사를 추가하려면 별도 장치의 위쪽 힘을 측정하고 제어하는 설계가 필요하다.

## 7. 보고서와 5분 발표

보고서는 **선정 동기 → 연구 문제·가설 → 이론 → 장치·변인·절차 → 결과 → 해석 → 오차·한계 → 배운 점** 순서로 작성한다. 무엇을 구현했는지와 무엇을 관찰·검증했는지를 구별한다. 코드 양이나 차량 외형의 수보다 결과와 이론을 연결하는 설명이 평가 근거가 된다.

| 발표 구간 | 내용 |
| --- | --- |
| 0:00–0:30 | 왜 착지 충격과 기체 소비를 함께 연구하는가? |
| 0:30–1:20 | 자유낙하·충격량·감쇠의 핵심 식과 가설 |
| 1:20–2:10 | 통제 변인과 축소 장치 설계 |
| 2:10–3:40 | 그래프 2–3개와 짧은 시연, 측정 범위의 절충 후보 |
| 3:40–4:40 | 물리적 해석·한계·배운 점 |

시연은 위 결과 설명 시간 안에 약 20초로 준비한다. 전체 발표는 5분 이내로 연습하고, 그래프의 단위와 “가정 모델·2ms 등가반력” 표기를 읽을 수 있게 남긴다.

현재 추가 검증 과제로 남는 것은 실물 측정, 가정값 민감도 분석, 계산 간격 수렴 검사다. 특히 2→1→0.5ms 수렴 검사는 **현재 UI에 구현되지 않았다**. 재생 속도 선택이나 +2ms 관찰을 그 검사의 대체라고 쓰지 않는다.


## v1.34에서 측정값을 읽을 때

첫 감속 시간과 첫 감속 지면 충격량은 같은 구간을 사용한다. 끝은 정지 접근(수직 속도 절댓값 0.01m/s 미만) 또는 반발을 처음 확인한 **2ms 표본의 끝**이다. 따라서 종료 수직 속도는 약간의 양수일 수 있다. CSV의 `contactEndTime`과 `contactEndVelocityY`를 함께 보고, 이 시간을 정확한 속도 0 교차시각이나 진동이 끝난 시간으로 적지 않는다.

라이브 선형 스프링 에너지와 CSV `springEnergyJ`는 같은 시각의 위치·자세로 구한다. `stateCompression`은 이 현재 상태의 압축량, 기존 `compression`은 해당 단계의 힘 계산에 사용했던 압축량이므로 그 차이를 측정 오차로 해석하지 않는다. 분사 표현을 0.1배로 보거나 2ms씩 진행해도 계산 간격과 실험 조건은 동일하다. 그래프의 같은 색은 같은 실험을 뜻하며, 안정 착지 확대에서도 이 연결을 유지한다.
