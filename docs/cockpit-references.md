# 운전석 재현 자료와 적용 범위

조사일: 2026-11-11. 기존 차량의 연식과 세대에 맞는 제조사 자료, 제조사가 제공한 전시 차량, 원 촬영자의 사진을 우선했다. 아래 자료는 형태와 배치를 확인하는 참고 자료이며, 제조사의 설계 도면이나 실측 치수를 확보했다는 뜻은 아니다.

기본 원칙은 차량 GLB에 이미 들어 있는 실내 형상·스티어링 휠·계기판을 활용하고, 운전자의 눈 위치를 그 실내에 맞추는 것이다. 모든 차에 같은 가상의 대시보드를 덧씌우면 실제 차종의 특징과 좌우 운전석이 사라진다. 형상이 없는 부분을 보완할 때도 아래 세대별 배치를 따른다.

## 구현과 검수 기준

- 원 모델의 운전석 좌우, 스티어링 휠 중심, 시트와 페달 방향을 먼저 확인한다. 카메라를 차체 정중앙이나 보닛 위에 두지 않는다.
- 시야에 실제 대시보드 상단, 앞유리 테두리, 가까운 A필러와 도어 안쪽이 자연스럽게 들어오게 한다. 카메라 근거리 절단면이 휠·계기판을 잘라내는지 확인한다.
- 기존 스티어링 휠 형상이 있으면 그 축과 중심을 기준으로 조향 애니메이션을 적용한다. 새 휠을 겹쳐 놓지 않는다.
- 속도 등 시뮬레이션 값은 해당 차종의 계기 위치에 맞춰 표시한다. Model 3처럼 중앙 화면이 주 계기인 차량에는 별도의 가상 운전자 클러스터를 추가하지 않는다.
- 좌우 둘러보기에서도 원 모델의 시트·도어·센터 콘솔이 연결되어 보여야 한다. 앞만 향한 평면 오버레이로 실내가 있다고 표현하지 않는다.
- OEM 실측 카메라 위치·계기 치수·모든 트림을 검증한 것은 아니다. 카메라 높이, 시야각, 화면 내용과 일부 보완 형상은 시뮬레이터 조정값이다.

## 자료 사용과 모델 출처

이 문서의 제조사 사진 링크는 연구·비교용 출처다. 웹에 공개되어 있다는 이유만으로 사진을 게임 텍스처나 배포 자산으로 사용하지 않는다. Toyota 사진 페이지는 편집 목적 사용으로 한정하고, Petersen은 개인·미디어 편집·교육 목적과 출처 표시 조건을 안내한다. Mazda와 BMW 사진은 이 조사에서 재배포 허가를 별도로 확보하지 않았다.

Steve Jurvetson의 Roadster 사진은 Commons 기록상 **CC BY 2.0**이며 [원 라이선스](https://creativecommons.org/licenses/by/2.0/)가 연결되어 있다. 실제 파일을 배포한다면 저작자·원문·라이선스·수정 여부를 함께 표시해야 한다.

이번 자료 조사는 외부 차량 GLB를 새로 도입하지 않는다. 현재 차량 모델의 저작자와 이용 조건은 기존 차량별 provenance와 자산 출처 기록을 따른다. 차종이 불명확한 범용 실내나 게임에서 추출한 자산을 실제 해당 차량의 운전석이라고 표시하지 않는다.

실내 원형을 사용할 수 없는 모델의 보완 형상은 `dist/js/reference-cockpit.js`에 분리했다. Urus, E30, Supra, Cybertruck/Model 3 계열을 구분하고 나머지는 명시적인 근사 실내로 처리한다. 이 모듈은 새 외부 파일을 내려받지 않으며, 계기 수치에 실제 시뮬레이션 속도·출력·잔량을 사용한다. 엔진 회전수 입력이 없으면 임의 RPM을 만들지 않고 출력 계기로 표시한다. 지도 모양 화면은 실제 위치를 추적하는 내비게이션이 아닌 시각적 보완이다.
