# v1.43 공기 저장·충전 보정 근거

이 문서는 실제로 판매되는 부품의 정격을 참조한 **가상 개조 장치**의 계산 근거다. Tesla가 해당 부품을 사용한다는 뜻이나, 모든 차량에 물리적으로 장착 가능한지 검증한 설계도가 아니다. 충전 시간은 실측 보증값이 아니라 명시된 초기 상태와 열전달 가정에 따른 수치 예측이다.

압축기의140kg 장치를 모든 차량에 숨겨 넣었다고 가정하지 않는다. 충전 버튼은 정차한 차량이 외부 고압 공기 충전 장치에 연결된 상황을 나타낸다. 실제 전기 입력은 별도로 누적하며, 차량 배터리를 소모하지 않는다. 내부 시험용으로 battery-powered 설정을 명시하면 기존처럼 배터리 한도를 적용할 수 있다.

## 질량과 에너지 계산

초기 상태는 주위와 용기 모두293.15K(20°C), 저장 체적0.108m³, 절대압력25.101325MPa다. 실제 공기 상태방정식으로 구한 초기 기체 질량은 **30.334060kg**이며, 종전의250kg을 유지하기 위해 체적이나 압력을 역산하지 않는다. 운용 충전 목표는 그99%인30.030720kg이다.

전기 압축기의300L/min는 압축된 탱크 부피 유량이 아니라 흡입 자유 공기 환산 유량이다. 질량 유량 상한은 주위 공기 밀도×0.300m³/60s로 변환한다. 기본20°C에서는 약0.006kg/s이다. 이전0.5kg/s 가정과 혼동하지 않는다.

전기 소비량은7.5kW 모터 정격에 실제 가동 시간 비율을 곱해 계산한다. 모터 정격은 실측 전력 곡선이 아니므로 보수적 전력 추정이다. 압력 한도로 정지하는 동안 압축기 전력은0이 되며, 강제로 빠르게 채우거나 시뮬레이션 시간 배율을 바꾸지 않는다. 추가로3단 중간 냉각의 등엔트로피 압축 일/효율0.65가 가용 전력을 넘으면 유량을 제한한다. 효율0.65는 실측치가 아닌 가정이다.

용기 에너지는 U=m·u(밀도,T)로 계산한다. 충전은 유입 엔탈피 Δm·h(P,Tin)를 더하고 벽으로 전달된 열을 뺀다. 분사 시에는 평균 상태의 유출 엔탈피를 빼며, 실제로 빠져나간 질량 비율을 추력에도 적용한다. 같은 계산을 착지 예측과 실제500Hz 적분에서 공유한다.

압축기 전체 에너지 검산은 전기 입력+흡입 공기 엔탈피=저장 탱크로 들어가는 엔탈피+방열이다. 따라서 후냉각기가 버리는 열을 무조건 전기 입력과 같다고 놓지 않는다.

## 열전달과 적용 한계

기체와 용기 벽을 두 개의 유한한 열 저장체로 나눈다. 벽 열용량은57.6kg×800J/(kg·K)=46,080J/K, 기체-벽 전달계수는80W/K, 벽-주위는30W/K다. **이 세 값은 제조사가 제공한 용기 열응답 데이터가 아닌 민감도 분석용 가정**이다. 벽-주위15/30/60W/K를 비교하여 예상 충전 시간이 열교환 가정에 얼마나 좌우되는지도 기록한다. 고정40kW 능동 냉각이나 주위 온도 아래로의 강제 냉각은 없다.

압력이 운용 한도에 닿으면 흡입을 줄이거나 멈추고 자연 냉각을 기다린다. 그러므로 자유 공기 유량만으로 나눈 최소 주입 시간과99%질량까지의 실제 경과 시간은 다르다. UI 예상 시간에도 이 대기를 포함한다.

단열 분사 때문에 기체 온도가 하한에 도달하면 실제 부품 운용 범위에 맞춰 유량을 차단한다. 온도나 질량을 순간적으로 되돌리지 않는다. 벽의 열이 기체로 전달되면 제한된 만큼 다시 분사할 수 있다. 이 처리도 실제 밸브 내부의 복잡한 유동·결빙·습도·열응력을 재현하는 것은 아니다. 시뮬은 건조 공기, 균일 용기 온도, 단일 기체상을 가정한다.

## 물성 검증과 재현

EOS 계수는 [CoolProp7.2.0 Air.json](https://github.com/CoolProp/CoolProp/blob/v7.2.0/dev/fluids/Air.json)의19개 잔차 항과 이상기체 항을 사용했다. 원 논문은 Lemmon, Jacobsen, Penoncello, Friend(2000), DOI10.1063/1.1285884다. CoolProp는MIT 라이선스이며 수식 계수와 출처를 보존했다.

독립 설치한CoolProp7.2.0의HEOS::Air로233.15–450K,0.101325–30.101325MPa의30개 참조 상태를 생성했다. JavaScript 구현의 밀도·내부에너지·엔탈피·정압/정적 비열은 최대 상대오차2.3×10⁻⁹ 이내에서 일치했다. 이 수치는 **구현 일치 오차**이며 원 물성식의 실험 불확도나 전체 차량 시뮬레이션의 정확도를 뜻하지 않는다.

- 참조 값: tests/air-eos-reference.json
- 물성 구현 검사: tests/air-eos.test.mjs
- 실제 유량·충전·유한 벽 열·전력 검사: tests/air-recharge.test.mjs
- 분사 에너지 보존·시간 간격 수렴: tests/air-blowdown.test.mjs
- 별도 충전 감사 결과: outputs/v143-charge-audit.json

계산 영역은150–1500K의 단일 기체상으로 제한한다. 적용 범위를 벗어나면 조용히 온도를 고정해 열을 만들어내지 않고 오류를 낸다. 실제 하드웨어 운용 하한은 이 물성 계산 하한보다 높게 설정한다.

## 보정 후 충전 감사 결과

조건:250bar 게이지압,108L,20°C,외부 PE300 등급 충전소,기체와 벽 초기20°C,목표99%. 계산 간격0.5초로 직접 적분했다.

|---|---:|---:|---:|
| 50% | 141.94분 | 41.13분 | 5.141kWh |
| 1% | 192.82분 | 82.26분 | 10.283kWh |
| 90% | 49.82분 | 7.55분 | 0.944kWh |

50% 시작 조건에서 벽-주위 열전달계수를15/30/60W/K로 바꾸면 총 충전 시간은 각각 **247.84/141.94/90.60분**이다. 따라서142분을 실제 제품의 확정 충전 시간이라고 말할 수 없다. 모터를 실제로 돌린 시간의 환산값은 모두41.13분이며 나머지는 주로 운용 압력 한도에서 냉각을 기다리는 시간이다.

UI는 같은 방정식을30초 간격으로 예측하고 캐시한다. 위 감사의 예측 오차는0.5초 적분 기준으로40.5–69.5초였으며,1–4시간 규모의 예상치다. 열전달계수의 불확실성은 이 수치 적분 오차보다 훨씬 크다. 주위 온도, 시작 기체·벽 온도와 사용한 기체량이 달라지면 결과도 달라진다.

전 사례에서 압력 한도 초과와 차량 배터리 소모는 없었다. 질량·기체와 벽의 총 에너지·외부 전력 합계를 별도로 검산했으며, 가장 긴 감사의 누적 에너지 잔차도0.002J 미만이었다.
