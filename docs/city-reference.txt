서울 강남역 자유 주행·비행 — v1.20

좌표 원점: 위도 37.4979, 경도 127.0276.
범위: 남 37.4912 / 서 127.0191 / 북 37.5046 / 동 127.0361.
가로 약 1.50 km, 세로 약 1.49 km. X는 동쪽, Z는 남쪽이며 길이는 m.

실제 데이터
- OpenStreetMap의 주행 가능한 도로 중심선과 건물 윤곽.
- 건물 높이 또는 층수, 차로 수 또는 폭 태그가 있으면 이를 우선 사용.
- 지하 도로와 지하 건물, 보행 전용 경로는 지상 주행 모델에서 제외.
- 도로 데이터는 실행 시 외부 서버를 호출하지 않고 동봉한 JSON으로 로드.
- 출처·원시 응답 해시·쿼리·시점은 dist/assets/city/provenance.json.

단순화한 부분
- 도로 폭 태그가 없으면 차로 수 × 3.15 m + 0.8 m, 차로 수도 없으면
  도로 분류별 폭을 사용한다. 중심선 자체는 임의로 새로 그리지 않는다.
- 건물 높이가 없으면 층수 × 3.3 m, 둘 다 없으면 바닥면적과 고정된
  난수 규칙으로 시각적 높이를 생성한다. 이 높이는 실측 제원이 아니다.
- 창, 가로등, 옥상 기기는 절차적으로 표현한 장식이다. 나무는 공개
  3D 모델을 배치하며, 하늘·노면은 별도로 촬영된 공개 환경 자산을 사용한다.
- 지형은 평탄하게 단순화한다. 실제 거리의 사진·위성·정밀 3D 스캔이나
  현재 도로 공사·차로 운영·신호 체계·교통량을 재현하는 서비스가 아니다.
- 건물 충돌체는 원래 윤곽 안에 놓인 3 m 이하 간격의 축 정렬 띠로
  근사한다. 회전된 건물의 전체 바운딩박스가 도로를 막지 않게 한다.

주행·비행 조작과 물리
- W/A/S/D: 지상 가속·제동 후 후진·조향, 공중 W/S 추진·A/D 선회(옆이동 모드는 설정에서 선택).
- Space: 상승. F: 후방 추진 가속. Shift: 지상 후륜 핸드브레이크 드리프트. H: 현재 높이 유지 켜기·끄기.
  지상 H의 목표는 0.8 m이며, Space를 누르면 수동 상승이 우선한다.
  Space를 놓으면 H에 저장한 목표 높이로 돌아간다.
- B: 지상 타이어 제동, 공중에서는 속도 반대 방향의 짐벌 분사 감속.
  방향 입력 중 높이 보정이 켜져 있으면 분사 추력을 함께 요청한다. 공중 제동도 가스를
  소모하며 추력 한도·밸브 지연을 따른다. 속도를 강제로 0으로 만들지 않는다.
- Q/E: 공중 기수 회전. 화살표: 공중 기수·좌우 기울기, 지상 가속·후진·조향.
- V: 힘 벡터. P: 일시정지·재생. R: 출발점 복귀·탱크 재충전.
- C: 추적·운전석·자유 카메라. 추적 시점의 드래그는 자유 시점으로 전환한다. 운전석에서는 드래그로 실내에서 둘러보고, 휠로 시야각을 조절하며, 더블클릭으로 정면에 복귀한다.
- 차종별 착지 실험과 같은 가상 개조 질량, 900 L·35.875 MPa·300 K 탱크를
  사용한다. 초기 기체는 약 375 kg이며 배출에 따라 질량·압력·온도가 줄어든다.
- 페달 해제 감속, 타이어 마찰과 미끄럼, 공기저항, 노면 요철, 건물 충돌을
  계산한다. 공통 교육용 구동계이며 차종별 순정 성능을 재현하지 않는다.
- 착지 실험은 질량 비교용 5종 × 3방식 15회이며, 도시 차량 전체 목록과 독립적이다. 출발 높이 입력은 유지한다.
  도시 수동 주행은 통제된 착지 비교와 구분한다.

강남 건물 보강 — v1.17
- 사용자가 말한 자율주행은 WASD 직접 자유 주행으로 확인했다. 별도 자동 운전은 추가하지 않았다.
- GT Tower East, 삼성 서초타운 3동, 교보타워, 부띠크모나코: 자체 재현 GLB 2개, 총 약8.39 MB·85,914삼각형·21재질 메시.
- docs/research의 OSM relation outer rings를 각각 복구한다. convex envelope를 통째로 충돌체로 사용하지 않는다.
- 실제 모델의 주요 매스별 높이·기단·상부 연결부·빈 공간을 반영하는 충돌체로 대체한다. 기존 중복 부속 way 박스도 제거한다. GT 파형은 직선 중심부 충돌로 단순화했다.
- 나머지 주변 건물의 입구/창틀/캐노피/수직 핀/난간은 추정 장식이다. 실사나 전수 복제라는 의미가 아니다.
- 공개원본 Mobiltech FBX는 재배포 조건 때문에 사용하지 않았다. 모델 출처/형태 근거/원본과의 차이는 assets/city-buildings/README.txt, manifest.json, provenance-extra.json과 docs/gangnam-architecture-sources.json에 남겼다.
- A/D가 공중 상태에서 조향각을 0으로 만들던 분기를 수정했다. 앞바퀴 조향은 유지하되 공중 접지 마찰은 생성하지 않는다. 일시정지 중 운전 입력은 자동 재개한다.
- 재생성: node scripts/prepare-landmark-footprints.mjs, node scripts/build-gangnam-landmarks.mjs, node scripts/prepare-extra-gangnam-buildings.mjs. 기존 fetch-gangnam.mjs만 실행해도 별도 landmark manifest가 복구한 relation은 유지된다.

주행·실험 보강 — v1.18
- 공중방향입력은 노즐만꺾이고 추력0이던 조건을 수정. 공중 기본 A/D는 기수회전, W/S는전후추진. 예전수평옆이동은 실험패널의공중A/D선택으로복원가능. Q/E기수회전·화살표자세·B감속은유지.
- 조작중높이보정은 방향입력동안만유한기체추력으로수직속도를보정한다. H는지속유지, Space는수동상승우선. 목표높이입력과착지보조(하강약.6m/s·수평감속)를추가. 수동입력시착지보조해제. 네바퀴접지시분사없이제동.
- 도시실험노면4종μ1.15/.65/.15/0, Crr0–.08, 항력토글, 동쪽/남쪽바람±30m/s, 노면요철0–1. R은차량/탱크초기화,실험설정유지. 기본조건버튼으로설정복구. 착지실험은별도통제조건.
- B처음누름시수평속도2m/s이상에서측정시작. 0.1m/s이하정지까지실제경로거리·시간,50ms평균최대감속. 충돌·접지상실·분사·B해제·설정/차체변경·일시정지·60초미정지무효. 최근6회CSV에초기속도와모든조건포함. 반응거리제외; 동일속도/경로/차체비교필수.
- 설정select/체크박스변경후운전포커스복구, Escape는입력칸에서도실험패널을닫고운전복귀.

지상 조향 보강 — v1.19
- 숫자 입력창으로 포커스가 옮겨지면 모든 운전 입력을 해제한다. Enter로 운전 포커스 복귀, Escape로 패널 닫기와 복귀. 키보드와 화면 포인터 입력은 따로 추적하며 초기화·일시정지·창 전환 때 함께 정리한다.
- 지상 전진 중 A/D를 누를 때 4–12 m/s 구간에서 코너링 보조를 점진 적용한다. 12 m/s 이상에서는 최대 가속 요청을 45%로 제한해 가속과 조향이 타이어 접지력을 나눠 쓰게 한다. 직선·저속·후진·공중 입력은 그대로이며 실제 제조사 주행 제어가 아닌 키보드 운전용 보조다.
- 앞바퀴 조향과 타이어 힘이 실제 차체 회전을 만든다. 차체의 방향이나 속도를 강제로 바꾸지 않으며 빙판·무마찰 조건에서 접지력을 추가하지 않는다. 정차 중 A/D는 앞바퀴만 꺾고, W 또는 S로 움직일 때 진행 방향이 바뀐다.
- 실험 패널을 닫아도 현재 노면의 마찰계수를 계기판에 표시한다. 조향 키와 가속 입력을 계기판과 화면 버튼에 표시한다.

조작과 드리프트 — v1.20
- W/S와 화살표 기본 운전은 유지하고, 기존 Shift 추진 부스트는 F로 옮겼다. F는 실제 유한 기체와 노즐 추력을 쓰며 B 제동이 우선한다. Shift는 공중에서 부스트나 제동 분사를 만들지 않는다.
- 지상 Shift는 후륜 기계식 핸드브레이크 입력이다. 앞바퀴 조향·구동은 유지하고 뒷바퀴 잠김과 타이어 종횡 미끄럼에서 차체 회전을 계산한다. 기본 노면 마찰계수나 차체 회전 속도를 강제로 바꾸지 않는다. Shift 중에는 자동 페달 해제 제동과 일반 코너링 토크 보조를 해제하고 실제 앞바퀴 조향 범위를 넓힌다.
- A/D와 Shift를 짧게 눌러 진입한 뒤 Shift를 놓고 조향해 회복한다. 오래 누르면 회전이 커질 수 있다. B는 네 바퀴 서비스 제동을 우선한다. Shift가 섞인 B 기록은 일반 제동 비교에서 제외한다.
- 고속에서 정상 조향 입력이 1도 이하로 작아지던 제한을 조정해 속도별 랙 범위의 30%를 남긴다. 실제 물리 앞바퀴 각도와 모델 표시가 동일하며, 접지 한계는 기존 타이어 힘 계산을 따른다. 100 km/h 출발·2초 W+A 시험에서 약 1도였던 바퀴 각도가 약 4.2도로 바뀌었다. 정차 최대각과 회전 시 구동 토크 보조는 유지한다.
