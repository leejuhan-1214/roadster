## 실측 데이터와 추정의 구분

`dist/assets/city/provenance.json`에 보존된 OSM 원자료는 강남역 기준 북위37.4912–37.5046, 동경127.0191–127.0361 범위다. 원점은37.4979,127.0276이며 원자료에는 도로500개와 건물1879개가 있다. 건물 외곽선과 도로 중심선은 해당 공개 지도에서 왔지만, 누락된 높이·폭·재료·창문·간판은 렌더링 가정이다. 랜드마크는 별도 출처와 모델 범위를 따른다.

원자료 영역 밖으로 연결한 생성 구역은 실제 서울 도로의 연속 측량이 아니다. 무한 주행을 위한 절차 생성 도시이며, 원본 강남역과 구분해서 안내한다. 지도 원자료, 생성 규칙, 외형 장식과 물리 충돌은 서로 다른 계층이다.

## 이번 일반 건물 외벽 변경

`city-facades.js`는 기존 유리 출입구·캐노피·난간에 저층 상업 패널, 상부4개 층 이내 유리창·창틀·층 구분선을 추가한다. 실제 업체 이름이나 간판은 사용하지 않으며, 외벽 색은 ID에 따라 결정적으로 변한다. 문자열 ID도 별도 변화를 가져 생성 구역이 모두 같은 색으로 보이지 않는다.

장식은 건물 앞면에서 최대0.1m 이내로만 돌출한다. 보도나 차도를 덮는 큰 장식 충돌체를 만들지 않는다.6개 instanced 렌더 묶음과 최대10000개 상자 인스턴스 제한을 유지한다. `detailCenter`와 `detailRadius` 옵션으로 멀리 있는 생성 구역도 해당 지역 중심 기준의 상세도를 적용할 수 있다.

검증은 기존 랜드마크 통합 검사와 별도 외벽 범위 검사로 한다. 렌더 호출 수·유한 변환 행렬·차도 방향 돌출 한도·원거리 구역 상세 중심을 확인한다. 실제 현장 외관과 일대일로 같다는 보증이나 구조적 건물 안전 평가를 뜻하지 않는다.
