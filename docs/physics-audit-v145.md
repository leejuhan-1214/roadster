# v1.45 물리 계산 감사

2026-11-15 KST. v1.42.1의 `8a1ff7c`와 이번 수정의 독립 수치 실행을 비교한 기록이다. **실차 검증이나 배포 완료 기록이 아니다.** 아래 숫자는 명시한 회귀 시나리오의 결과이며, 다섯 차량의 전체 착지 비교표를 대신하지 않는다.

## 1. 대칭 착지에서 발생하던 회전

이전 `_resolveGround()`는 가장 낮은 꼭짓점 하나에만 법선 충격량을 적용했다. 완전히 수평인 차체의 바닥 네 점이 같은 높이일 때도 반복문의 첫 점이 선택되어, 외부 비대칭이 없는데 롤·피치 회전이 생겼다.

수정은 침투한 접촉점들을 함께 구성하고 누적 법선 충격량과 마찰 충격량을 반복해서 푸는 방식이다. 역방향 반복도 사용하여 접촉점 순서의 편향을 줄였다. 저속 접촉에서는 반발을 만들지 않는다. 위치 침투 보정과 속도를 바꾸는 물리적 충격량은 구분한다.

독립 직접 충돌 조건: 기본 차체, 초기 수평 자세, 초기 각속도 0, 수직 속도 -5 m/s, 바닥 침투 0.01 m, 중력 0. `_resolveGround()` 1회 호출 결과:

| 지표 | 이전 | 수정 후 |
| --- | ---: | ---: |
| 각속도 X (rad/s) | 2.018161 | 약 5.60×10⁻¹¹ |
| 각속도 Z (rad/s) | -1.042629 | 약 -3.85×10⁻¹¹ |
| 수직 속도 (m/s) | -4.274188 | 0.250000 |
| 운동에너지 (J), 초기 28,437.5 J | 24,515.846 | 71.093750 |

수정 후 잔여 에너지는 초기의 0.25%이며, 이 시나리오에 사용된 반발계수 0.05의 제곱과 일치한다. 이는 특정 충돌 계산의 검산이며 실제 차체의 반발계수 측정이 아니다.

또한 기본 `PhysicsSim`을 바퀴 아래 3 m에서 정지시켜 무분사 낙하했다. 공기저항·마찰·구름저항은 끄고 2 ms로 3초간 계산했다. 최대 각속도는 **2.482803 rad/s → 약 1.26×10⁻⁷ rad/s**로 줄었다. 수평 대칭 낙하가 임의로 한쪽으로 기울던 문제가 제거되었다.

## 2. 외부 토크 없는 회전의 에너지 증가

이전 자이로 항의 명시적 Euler 적분은 외부 토크가 없어도 회전 에너지를 증가시켰다. 이를 암시적 중점법으로 바꾸고, 자세에도 대응하는 Cayley 회전을 적용했다. 관성모멘트가 고정된 무토크 강체에서 회전 에너지와 세계좌표 각운동량을 함께 검사했다.

조건: 중력·접촉·공기저항·자세제어·분사 모두 끔, 기본 관성모멘트, 시간 간격 2 ms, 5초 실행. 각속도는 차체 좌표계 값이다.

| 초기 각속도 (rad/s) | 초기 회전 에너지 (J) | 이전 에너지 변화율 | 수정 후 에너지 변화율 |
| --- | ---: | ---: | ---: |
| (2, 3, 4) | 45,100 | +1.680044% | 약 -1.95×10⁻¹²% |
| (10, 5, 2) | 94,500 | +38.304748% | 약 -1.11×10⁻¹³% |

수정 후 세계좌표 각운동량의 상대 변화율은 두 경우 모두 약 10⁻¹²% 수준이었다. 1 ms와 0.5 ms 독립 실행에서도 부동소수점 오차 수준의 보존을 확인했다. 에너지 보존은 모든 운동의 위상 오차가 0이라는 뜻은 아니다.

실제 한쪽 노즐을 분사하는 추가 회귀에서는 각 단계의 회전 에너지 변화와 `Δt × τ · ω_mid`가 일치하는지 확인했다. 자유 회전에서 강제로 에너지를 일정하게 만드는 보정만으로 검사를 통과한 것이 아니다.

## 3. 시간 간격과 최대 등가반력

첫 절의 3 m 무분사 낙하를 시간 간격만 바꾸어 다시 계산했다. 값은 **수정 후 기본 물리 형상의 독립 회귀 실행**이다.

| 시간 간격 | 최대 등가 지면반력 (kN) | 3초 누적 지면반력 충격량 (N·s) | 최대 각속도 (rad/s) |
| --- | ---: | ---: | ---: |
| 2 ms | 6,876.695 | 66,930.371327 | 1.26×10⁻⁷ |
| 1 ms | 13,768.854 | 66,930.371109 | 1.98×10⁻⁸ |
| 0.5 ms | 27,216.756 | 66,930.371132 | 2.44×10⁻⁹ |

등가반력은 `연속 접촉력 + 해당 단계의 침투 보정 충격량 / Δt`로 계산한다. 이상적인 강체 충격량을 더 짧은 시간에 나누면 최대 등가반력은 커질 수 있다. 따라서 위 최대값이 두 배 가까이 된다는 사실만으로 운동량 계산이 발산한다고 판단하지 않는다. 누적 충격량과 상태의 수렴을 따로 확인해야 한다.

이 값을 실제 재료의 순간 최대 응력, 차체 파손 한계, 탑승자 충격 가속도로 사용하지 않는다. 유한 시간의 물리적인 최대 충격력을 예측하려면 차체·타이어·지면의 변형과 접촉 시간에 관한 별도의 검증된 모델이 필요하다. 평균 반력, 연속 접촉력 최대, 보정 포함 등가 최대, 충격량은 서로 다른 지표다.

평지 무입력 정지의 별도 5초 검사는 2/1/0.5 ms 모두 위치 이동 0, 공기 소비 0이었다. 최대 속력은 약 8.35×10⁻¹⁶ m/s로 수치 반올림 수준이었다.

## 4. 공압 모델의 범위

초기 저장량 **900 L / 375 kg**, 절대압력 **35.875 MPa**, 온도 **300 K**를 유지한다. 유한 탱크이며, 분사로 공기가 줄고 차량 질량·탱크 온도·압력이 변한다. 무한 추력이나 자동 자원 보충으로 대체하지 않는다. 공기 충전은 별도로 활성화한 정차 작업이며 배터리 에너지와 유입 엔탈피를 계산한다.

현재 방출은 일정 비열·이상기체·단열 근사다. 비충전 구간의 탱크 열교환을 0으로 둔다. 충전 중에는 모델에 정의한 벽면 열교환과 능동 냉각을 적용한다. 장기 주차 중 재가열, 매우 낮은 온도의 상변화, 고압에서 변하는 실기체 압축성·비열·열전달, 실제 탱크의 구조 질량과 공간 제약은 검증하지 않았다. 특히 약 35.9 MPa 상태를 이상기체식으로 계산한 질량이 실제 장치의 제작 가능성을 입증하지 않는다.

MathWorks 문서의 유한 체적 질량·에너지 수지 및 기체 모델 구분을 참고했으며, 이 시뮬레이터를 Simscape 또는 실차와 수치적으로 일치시켰다는 뜻은 아니다. 공기 소비량 감소를 같은 비율의 충전 전기에너지 감소로 해석하지 않는다.

## 회귀 검사와 보고서 사용

```sh
node --test tests/ground-manifold.test.mjs tests/rotation-conservation.test.mjs tests/pneumatic-boundary.test.mjs
```

회전 검사에는 두 초기 각속도와 2/1 ms의 조합, 5초간 최대 에너지·세계좌표 각운동량 오차, 한쪽 노즐의 회전 일이 포함된다. 이 다섯 검사는 독립 실행에서 통과했다. 접촉·공압 검사 및 전체 회귀의 최종 상태는 해당 실행 기록을 확인한다.

**v1.42.1로 작성한 보고서 수치를 새 버전의 결과로 옮기지 않는다.** 초기 공기량이 같아도 접촉 해법과 회전 적분이 바뀌면 반력·압축·회전·정착 과정의 결과가 바뀔 수 있다. 기존 보고서의 수치는 v1.42.1 결과로 보존하거나, 새 버전에서 동일 조건의 네 방식을 다시 실행한 표로 교체해야 한다. 이 문서의 최소 회귀 시나리오 값과 실제 차체 형상을 로딩한 착지 실험 값도 구분한다.
