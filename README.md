# Roadster Landing Lab · v1.23

같은 높이에서 내려오는 차량의 충격을 비교하고, 충격을 줄이는 착지 방법을 찾는 3D 실험실입니다. 별도 도시 주행 모드에서는 강남역 실제 도로 배치를 따라 운전하거나 가상 냉가스 추진기로 비행할 수 있습니다.

[실험실 실행](https://leejuhan-1214.github.io/roadster/) · [실험 방법과 보고서 참고](docs/landing-experiment.txt)

## 현재 기능

- **착지 중 Space:** 실험 시작 후 지면에 닿기 전 Space을 누르고 있으면 유한 기체를 소모하는 상승 추진기를 켭니다. 놓으면 선택한 착지 방식으로 복귀합니다. 수동 개입 결과에는 표시와 분사 시간(초)을 남기고 자동 최소값·기준 대비 감소율 계산에서는 제외합니다. 일시정지·창 전환·다음 실험에서 입력을 초기화합니다.

- **01 착지 실험:** 선택한 차체를 같은 조건으로 비교하거나 한 차체의 자유 낙하·지면 전 추력 제동·완만한 하강 제어를 비교합니다. **모든 차체 × 3방식**은 같은 출발 높이로 13종 × 3방식, 총 39회를 실행합니다. 출발·제동 높이의 고정 상한은 없으며 유한한 0 이상 수치를 입력합니다. 목표 하강속도와 바퀴별 스프링·감쇠도 조정합니다.
- **구조 탐색:** 원본 외형과 착지용 탱크·서스펜션·추진기를 살펴봅니다. 검색, 부위 분류, 숨김, 단독 보기, 확대, 분해·조립을 지원합니다. 원래 앞뒤·좌우 관계를 유지하며 바깥으로 벌어지고, 같은 조립체의 재질 표면은 함께 이동합니다. 100%에서 조립체 사이 간격을 확보합니다.
- **강남 건물:** GT Tower East·삼성 서초타운 3동·교보타워·부띠크모나코의 특징적인 외형을 GLB 2개로 재현했습니다. 실제 OSM 위치와 다중 윤곽을 복구하고, 저층부·연결부·빈 공간에 맞춘 충돌체를 사용합니다. 주변 일반 건물에는 유리 외벽·출입구·캐노피·옥상 난간을 추가했습니다. [모델 출처와 재현 범위](dist/assets/city-buildings/README.txt).
- **제동 높이 비교:** 현재 차체의 자유낙하 기준과 출발 높이의 10/25/50/75/100%에서 추력 제동하는 5회를 비교합니다. 결과에서 같은 조건의 자유낙하 대비 반력 감소율, 첫 접촉부터 첫 수직 정지까지의 시간·지면 충격량, 최대 압축과 반발 높이를 확인하고 CSV로 저장합니다.
- **도시 주행 실험:** 접이식 실험 패널에서 노면·구름저항·공기저항·바람·요철을 바꾸고, 가속 후 B를 눌러 제동거리·시간을 측정합니다. 충돌·이륙·추력 작동·정지 전 B 해제·조건 변경은 무효 기록으로 구분합니다. 같은 초기 속도·차체·경로에서 비교해야 합니다.
- **03 도시 주행:** 강남역 주변 OpenStreetMap 도로·건물 배치를 사용합니다. 주행·상승·부스트·고도 유지·공중 분사 이동을 조작하며 속도·높이·수직속도·기체량을 확인합니다. 페달 해제 감속, 제동 후 후진, 속도에 따른 조향, 타이어 접지·미끄럼과 건물 충돌을 계산합니다.
- 실시간 높이·수직속도·등가반력·하중·기체량을 표시하고, 결과 표·첫 접촉 기준 힘 그래프·CSV를 제공합니다.
- 타이어 형상에서 바퀴 축을 구해 원본에 포함된 조향·기울기를 중립 축으로 보정합니다. 타이어·휠·브레이크를 함께 보정한 뒤 회전부와 고정부를 구분합니다.
- 노즐과 덮개는 차종별 외형 표면에 맞춰 매립합니다. 외부 나무 모델, 촬영한 하늘 HDR과 도로 재질을 사용하며, 거리에 따른 나무 세부 수준·그림자 갱신 조절과 물리 상태 보간을 적용합니다.

도시 주행 입력은 03 모드에서만 작동합니다. W/S 기본 주행을 유지하며 F는 유한 기체 추진 가속, Shift는 지상 후륜 핸드브레이크입니다. A/D와 Shift를 짧게 눌러 미끄러짐을 시작하고 Shift를 놓아 조향으로 자세를 회복합니다. B는 전체 제동을 우선하며, Shift 입력이 섞인 제동 측정은 비교 결과에서 무효로 구분합니다. 숫자 설정을 편집하면 누르고 있던 운전 입력을 해제하고, Enter나 Escape로 운전 포커스로 돌아갑니다. 키보드와 화면 버튼의 입력을 각각 추적해 동시에 사용해도 조향이 끊기지 않습니다. 지상에서 W와 A/D를 함께 누르면 속도에 따라 구동 토크를 조절해 회전할 여유를 확보합니다. 현재 노면 마찰계수와 입력 중인 조향 방향을 계기판에서 확인할 수 있습니다. 일시정지 중 운전 키나 화면 페달을 누르면 주행이 재개됩니다. A/D 앞바퀴 조향은 지상·공중에 모두 표시되며 공중 타이어 마찰력은 적용하지 않습니다. 착지 실험은 통제된 자동 입력을 사용하며, 이전 수평 이동 시연·충돌 시연·코스는 다시 노출하지 않습니다.

## 사용 방법

1. **착지 실험**에서 차체와 출발 높이를 선택합니다. 높이는 하중이 없는 타이어 최하단과 지면 사이의 거리입니다.
2. **현재 차체 실험**, 2종 이상을 고른 **선택 차체 비교**, **착지 3방식 비교**, 또는 **모든 차체 × 3방식**을 실행합니다. 비교 묶음 안에서는 같은 높이·스프링·감쇠·초기 탱크 조건을 사용합니다.
3. **비교 결과**에서 등가반력, 접촉 최대 하중, 접촉 속도, 기체 사용량과 착지 상태를 함께 봅니다. 제동 높이 또는 서스펜션 설정 중 하나씩 바꾸어 다시 비교합니다.
4. 보고서용으로 **전체 결과 CSV**와 **전체 시간기록 CSV**를 저장합니다. 최근 78회를 기준으로 이전 묶음 전체를 정리하므로 39회 비교가 중간에서 잘리지 않습니다. 다차종·다방식 결과의 그래프는 차체를 선택해 3방식씩 비교합니다. 새로고침 전에 기록을 내보냅니다.
5. **구조 탐색**에서는 드래그로 회전하고 슬라이더 또는 스크롤로 분해합니다. `조립 초기화`로 복원합니다.

`P`: 진행 중인 실험 일시정지/재생 · `C`: 카메라 · `V`: 힘 벡터 · `R`: 초기화. 초기화·중단은 완료된 비교 기록을 지우지 않습니다.

도시 조작은 다음과 같습니다. `조작` 버튼으로 화면 버튼도 표시합니다.

| 조작 | 기능 |
| --- | --- |
| `W A S D` | 지상 가속·제동 후 후진·조향 / 공중 W/S 추진·A/D 방향 전환 |
| `Space` / `F` | 상승 분사 / 후방 추진 가속 부스트 |
| `Shift` + `A/D` | 지상 후륜 핸드브레이크 드리프트 · 놓으면 접지 회복 |
| `H` | 현재 높이 유지 켜기·끄기. 지상에서는 0.8 m를 목표로 상승 |
| `B` | 지상 타이어 제동 / 공중 속도 반대 방향으로 분사 감속 |
| `Q E` / 화살표 | 공중 기수 회전 / 기수·좌우 기울기. 지상 화살표는 가속·후진·조향 |
| 마우스 드래그 / 휠 | 자유 시점 전환 후 회전 / 확대·축소 |
| `C` / `V` / `P` / `R` | 카메라 전환 / 힘 벡터 / 일시정지·재생 / 출발점 복귀·재충전 |

`H` 유지 중 `Space`를 누르면 수동 상승이 우선하고, 놓으면 저장한 목표 높이로 복귀합니다. 공중 방향 조작 중에는 기본 높이 보정이 함께 실제 추력을 요청합니다. 실험 패널에서 보정을 끄거나 A/D를 기존 수평 옆이동으로 바꿀 수 있습니다. Q/E는 항상 기수 회전입니다. 목표 높이 유지와 착지 보조도 유한한 기체와 추력 한도를 따르며, 착지 보조 중 수동 운전 키를 누르면 해제됩니다. 공중 `B`도 가스와 추력이 필요하며 즉시 정지하지 않습니다. 지상에서 페달을 놓으면 완만한 제동, 저속에서는 정지 유지를 적용합니다. 가속도·속도 변화는 힘과 강체 계산으로 구하며 속도를 직접 덮어쓰지 않습니다.

## 실험 조건과 해석

평탄면, 무풍, 초기 속도 0, 수평 자세, 공기저항 OFF를 통제합니다. 접촉 마찰계수는 1.15, 구름저항계수는 0.015로 고정합니다. 기본 설정은 높이 3 m, 바퀴별 스프링 75 kN/m, 감쇠 6 kN·s/m입니다. 가상 탱크는 900 L·300 K·초기 절대압력 35.875 MPa이며, 이상 공기 약 375 kg을 담습니다. 기체 배출에 따른 질량·온도·압력 감소와 밸브 응답을 계산합니다.

최대 등가반력은 연속 접촉력에 수치적 접촉 충격량을 **2 ms**로 나눈 값을 더한 결과입니다. 그래프는 **10 ms 구간 최댓값**을 표시합니다. 이는 실제 재료의 순간 최대 응력이나 승객 상해 측정값이 아닙니다. 완료된 같은 조건의 비교 묶음에서 안정 착지하고 차체 접촉·서스펜션 한계 초과가 없는 결과만 최소값 후보로 삼습니다.

높은 출발점은 높이에 맞춰 첫 접촉 대기 시간을 늘립니다. 긴 비접촉 구간의 CSV는 기록 간격을 늘리고, 접촉 근처는 10 ms 기록을 유지합니다. 높이 상한을 없애도 중력 일정·평면 지면·공기저항 OFF라는 모델 범위는 같으며, 고고도 대기나 지구 곡률을 재현하는 것은 아닙니다.

이 프로젝트는 Tesla·SpaceX 또는 다른 제조사의 공식 모델이 아닙니다. 공개 아티스트 외형과 일부 제원을 이용하며, 제조사 OEM CAD·전체 부품명세·순정 서스펜션·차체 변형을 재현하지 않습니다. 추진기·탱크·서스펜션은 공통 교육용 가정 장치입니다. 차종별 질량 기준도 건조·공차·DIN·가정값으로 다르므로 결과를 실차 안전성 순위로 해석하지 않습니다.

도시 주행에도 착지 실험과 같은 차체별 가상 개조 질량과 900 L·35.875 MPa의 충전 탱크를 적용합니다. 추진·고도 유지·공중 제동은 기체를 소모하고, 압력이 낮아지면 가능한 추력이 줄어듭니다. 공통 가상 전기 구동계·타이어·서스펜션은 각 차량의 실제 엔진이나 주행 성능을 재현한 모델이 아닙니다. 도시는 노면 요철·공기저항·수동 입력을 사용하므로 통제된 착지 실험과 결과를 직접 합쳐 비교하지 않습니다.

## 로컬 실행과 검증

Node.js 24에서 검사합니다.

```sh
npm ci --ignore-scripts
npm run check
npm test
```

별도 빌드 없이 `dist/`를 HTTP 서버로 제공합니다. Python 3이 설치되어 있다면 프로젝트 폴더에서:

```sh
python -m http.server 8080 --directory dist
```

[http://localhost:8080](http://localhost:8080)을 엽니다. ES 모듈을 사용하므로 HTML을 파일로 직접 열지 않습니다. Three.js는 `dist/vendor/`에 포함되어 있습니다. 자동 검사는 수치·렌더 상태·차종별 형상·분해 배치·착지 UI 범위를 다루며, 실제 화면의 시점·가림·사용 흐름은 브라우저에서도 확인합니다.

[Pages 워크플로](.github/workflows/pages.yml)는 `main`의 `dist/`를 검사한 뒤 배포합니다. `dist/**`, `tests/**`, `package*.json`, 워크플로 변경을 push하면 실행되며 수동 실행도 지원합니다. 문서만 수정한 push는 자동 배포를 시작하지 않습니다. 예전 `gh-pages` 브랜치는 현재 배포 원본이 아닙니다.

배포 후 Actions의 build/deploy 성공과 공개 URL의 변경 내용을 확인합니다. 현재 기능과 이전 배포 기록을 혼동하지 않도록 과거 README는 [이전 버전 기록](docs/version-history.md)에 보존했습니다.

도시 주행은 접지한 각 타이어의 실제 미끄럼에 따라 연기와 연속 자국을 표시합니다. 연기160개·자국1600개로 제한하며 일시정지에서는 효과도 정지하고 R로 초기화합니다. Shift 후륜 제동은80ms 시정수로 서서히 적용되어 진입이 부드러워졌으며 B는 즉시 우선합니다. 차체 색상은 색상표 또는 자유 색 선택으로 바꿀 수 있습니다.


## v1.23 자유 조종과 측정의 경계

착지 실험 탭에 들어온 직후에는 실험장이 자유 조종 공간입니다. W/S로 움직이고 A/D로 조향하며 Space로 상승합니다. F 추진 가속, Shift 드리프트, B 제동, H 높이 유지, Q/E 회전, 화살표 자세 제어도 같은 DrivingController를 사용합니다. 별도의 상승 분사 화면 버튼은 제거했습니다. 숫자 입력·선택 상자·대화상자를 편집하는 동안에는 조종 입력을 받지 않습니다. 마우스로 화면을 누른 뒤 키보드로 조작하십시오.

현재 차체 실험 또는 비교 버튼을 누르면 자유 조종 상태를 폐기합니다. 차량 위치는 실험장 중심 x=0,z=0으로 돌아가며, 바퀴 아래 높이를 출발 높이로 맞춥니다. 속도·각속도는0, 차체 자세는 수평, 바퀴 회전·접촉 기록은 초기화합니다. 탱크는 실험의 초기 압력·온도·용적으로 다시 충전합니다. 따라서 미리 이동하거나 비행하며 기체를 소모해도 실험 시작 조건에 섞이지 않습니다.

측정 중에는 WASD 자유 주행을 차단합니다. Space만 첫 접촉 전 수동 상승으로 개입할 수 있습니다. 개입한 행은 수동 Space로 표시하고 자동 최적값 후보에서 제외합니다. 일괄 비교의 다음 차체도 매번 초기화하며, 완료 후에는 결과 창을 표시하고 멈춥니다. 다시 자유롭게 조종하려면 R 또는 초기화를 누르십시오. 실험 중단도 출발점 복귀와 자유 조종 재개를 수행합니다.

## 재현 가능한 수행평가 절차

1. 연구 질문을 “같은 높이에서 내려오는 차체의 착지 충격을 줄이는 방법은 무엇인가?”로 설정합니다.
2. 독립변인은 차체 또는 제동 방식 중 하나를 정합니다. 두 요인을 함께 바꿀 때는 차체×방식 표로 결과를 분리합니다.
3. 출발 높이, 스프링, 감쇠, 초기 탱크 조건을 통제합니다. 차체 비교에서는 총질량과 형상이 함께 달라지므로 단일 재질 효과로 해석하지 않습니다.
4. 자유 낙하 기준을 포함해 3방식 또는 제동 높이 비교를 실행합니다. 자동 비교 도중 Space를 누르지 않습니다.
5. 최대 등가반력만 보지 말고 첫 접촉 속도, 접촉 시간, 충격량, 압축, 반발, 기체 사용량을 함께 기록합니다.
6. 수동 분사 실험은 별도 탐구로 실시하고 누른 시간과 결과를 보존합니다. 자동 방법과 통제 조건이 다름을 보고서에 씁니다.
7. 요약 CSV와 시간기록 CSV를 함께 내려받습니다. 그래프의 시간0은 첫 접촉이지만 CSV의 time은 실험 시작부터의 시간입니다.
8. 최소값 후보에서 제외된 차체 접촉·한계 초과·불안정·수동 결과를 삭제하지 말고 제외 이유를 설명합니다.

물리 연결은 자유낙하 v²≈2gh, 운동량 변화 Δp=∫F_net dt, 충격 시간 증가에 따른 평균힘 변화, 탄성에너지 ½kx²와 감쇠 손실입니다. 지면 충격량만으로 전체 운동량 변화를 계산하면 중력과 추진기 충격량이 빠집니다. 모델의 등가반력 최대값은 수치 시간 간격에 의존하므로 실제 자동차 충돌시험 인증 수치로 사용하지 않습니다.

## 결과 필드 사전

- groupId / vehicleId / method: 비교 묶음·차체·선택한 자동 방식 식별자.
- height / brakeHeight / targetSpeed: 출발 간격(m)·분사 시작 높이(m)·목표 하강속도(m/s).
- initialMass / initialGas: 기체 포함 총질량과 초기 기체 질량(kg).
- touchdownTime / touchdownSpeed: 첫 접촉 시각(s)과 하강속도의 크기(m/s).
- peakGroundForceN: 연속 접촉 모델의 최대 지면 힘(N).
- peakEquivalentGroundForceN: 접촉 보정 충격량을2ms로 나눈 값까지 포함한 최대값(N).
- contactPeakG: 첫 접촉 이후 접촉 구간의 최대 하중 배수.
- groundImpulseNs: 첫 접촉부터 첫 수직 정지까지의 지면 충격량(N·s).
- totalGroundImpulseNs: 전체 측정 구간 지면 충격량으로 위 필드와 범위가 다릅니다.
- contactDuration / maxCompression / reboundHeight: 접촉 제동 시간(s)·최대 압축(m)·관찰 구간 반발 높이(m).
- manualLiftUsed / manualLiftDuration: 수동 명령 사용 여부·유지시간(s). 실제 밸브 유량 지속시간과는 다를 수 있습니다.
- manualLift: 시간기록 구간에 수동 명령이 있었으면1.
- gasUsed / status / settled / bodyStrike / bottomedOut: 기체 사용량(kg)과 착지·안정·차체 접촉·서스펜션 한계 판정.
- free_baseline_id / peak_force_reduction_percent: 통제 조건이 같은 유효 기준이 있을 때만 채우며 수동 개입에는 비웁니다.
